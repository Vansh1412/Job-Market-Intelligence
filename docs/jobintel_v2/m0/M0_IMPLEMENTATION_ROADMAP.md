# M0 Implementation Roadmap

Estimates are relative engineering sizing (S/M/L/XL), not calendar commitments. Each stage must preserve current India/USA behavior and pass market-specific acceptance gates. Paths are likely additions/changes inferred from current code, not authorized M0 edits.

## Optional enhancements

- FX-normalized purchasing-power or real-wage comparison (requires separate source/time policy).
- ML salary prediction for new markets (optional, only with lawful, sufficiently detailed data and independent temporal validation).
- Occupational transition graphs and causal skill scenarios (optional, evidence-intensive).
- Advanced trend forecasts or 3D product views (not prerequisites for core intelligence).

No milestone is started or approved by this plan. Exact existing files likely touched are tentative pending M1 architecture review.
