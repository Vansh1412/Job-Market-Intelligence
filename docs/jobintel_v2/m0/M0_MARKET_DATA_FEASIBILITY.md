# M0 Market Data Feasibility

Assessment date: 2026-11-03. Official-source checks were performed with official statistical agency / government pages. These are **starting sources**, not acquired datasets; no data were downloaded. Availability and current version must be rechecked at implementation time.

## Cross-market readiness judgment

- All three markets have plausible official aggregate sources for descriptive salary context. None of the sources above demonstrates row-level, job-ad-level salary data with enough predictors and reuse rights to train a comparable prediction model.
- Data are not directly comparable: earnings reference period, gross/basic/total cash, employee population, occupation edition, geography, and annualization differ. Preserve source-native values and define normalization explicitly.
- Statistical precision/suppression and licensing/attribution requirements must be documented per released table. “Public download” is not identical to blanket redistribution or ML-training permission.
- No country is “ready for predictive ML” based on this source check. Australia/UK/SG salary intelligence: feasible with engineering after provenance/definition review; predictive ML requires distinct evidence, likely not initially available from these aggregates.
